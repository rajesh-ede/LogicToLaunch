###  Programming — Operators

**Topic Covered:** Operators

Operators are symbols used to perform operations on values and variables.

#### Types of Operators

* **Arithmetic Operators:** `+`, `-`, `*`, `/`, `%`
* **Relational Operators:** `>`, `<`, `>=`, `<=`, `==`, `!=`
* **Logical Operators:** `&&`, `||`, `!`
* **Assignment Operators:** `=`, `+=`, `-=`, `*=`, `/=`, `%=`
* **Increment / Decrement:** `++`, `--`

###  Java Technology — Variables and Their Types

**Topic Covered:** Variables and Types of Variables

A **variable** is a named memory location used to store data that can change during program execution.

#### Basic Variable Declaration

```java
dataType variableName = value;
```

Example:

```java
int age = 20;
```

#### Types of Variables in Java

1. **Local Variable**

    * Declared inside a method, constructor, or block.
    * Scope is limited to that method or block.

2. **Instance Variable**

    * Declared inside a class but outside methods, constructors, or blocks.
    * Each object has its own copy.

3. **Static Variable**

    * Declared using the `static` keyword.
    * Belongs to the class rather than individual objects.
    * Shared among all objects of the class.
